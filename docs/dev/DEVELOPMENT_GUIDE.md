# Development Guide

## Before You Start Working
- [ ] Ensure you have Python 3.10+ installed.
- [ ] Ensure you have [Ollama](https://ollama.com/) installed on your machine.
- [ ] Ensure you have at least 16GB of RAM.

## Environment Setup

1. **Create a virtual environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your Indian Kanoon API key:
   ```env
   KANOON_API_TOKEN=your_api_token_here
   ```

4. **Pull the Local LLM via Ollama:**
   By default, the POC is intended to run Phi-3 Mini (or Llama 3.1).
   ```bash
   ollama pull phi3:mini
   # or, if you have a strong machine:
   ollama pull llama3.1:8b
   ```
   *(Note: Ensure `MODEL_NAME` in `src/rag_chain.py` matches the model you pulled).*

## The Normal Development Workflow

The development and testing lifecycle follows a strict sequence because each step depends on the data generated by the previous one.

### Testing Order

1. **Environment Setup** (Dependencies, `.env`, Ollama)
2. **Database Initialization**
   ```bash
   python src/init_db.py
   ```
3. **Fetch Judgments (Batch Workflow)**
   *(Requires Kanoon API token)*
   Use the category-based batch workflow to collect your 140-160 target cases across specific topics.
   
   *Step A: Search and save results*
   ```bash
   python src/fetch_judgments.py --step search --query "section 138 notice service" --category notice_service
   ```
   This creates `data/case_lists/notice_service_search_results.txt`.

   *Step B: Review and select*
   Copy the lines of the cases you actually want from that file into a new file: `data/case_lists/notice_service.txt`.

   *Step C: Fetch in bulk*
   ```bash
   python src/fetch_judgments.py --step fetch --ids_file data/case_lists/notice_service.txt
   ```
   *(The script will automatically skip duplicates and previously downloaded files).*
4. **Ingest Judgments into SQLite**
   ```bash
   python src/ingest.py --input data/sample_judgments/
   ```
5. **Chunk and Embed Data (ChromaDB)**
   ```bash
   python src/chunk_embed.py
   ```
6. **Test Hybrid Search**
   *(Run manually or via an interactive python shell importing `search.py`)*
7. **Test RAG & Citation Verifier**
   *(Run `python src/rag_chain.py` directly to see console test output)*
8. **Run the Streamlit UI**
   ```bash
   streamlit run src/app.py
   ```
